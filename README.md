# SUPHALAK 1985 — Corporate Website

บริษัท ศุภลักษณ์ 1985 จำกัด / SUPHALAK 1985 CO., LTD.

เว็บไซต์ต้นแบบ Next.js App Router (TypeScript + HTML/JSX + CSS) ดีไซน์ตามภาพที่อนุมัติ: กรมท่า-ทอง, สิงโตมงกุฎ, หน้าหลักธุรกิจค้าปลีก/ค้าส่ง/จัดร้าน, Responsive Desktop & Mobile.

## เริ่มใช้งาน

ต้องมี Node.js 22 ขึ้นไป (แนะนำ Node.js 24)

```bash
npm install
npm run dev
```

เปิด `http://localhost:3000` และทดสอบ Production Build ด้วย:

```bash
npm run typecheck
npm run build
npm run start
```

## โครงสร้างโค้ด

- `app/page.tsx` — หน้าเว็บไซต์และปฏิสัมพันธ์ (เมนูมือถือ, ค้นหา, ตัวอย่างสินค้า, รายการสอบถาม, ฟอร์มคัดลอกคำขอราคา)
- `app/globals.css` — ระบบดีไซน์ Responsive สีกรมท่า-ทอง
- `app/layout.tsx` — Metadata, SEO, ฟอนต์, favicon
- `components/Icon.tsx` — ไอคอนเส้นแบบมืออาชีพ (SVG)
- `public/images/lion.webp` — โลโก้สิงโตมงกุฎตามไฟล์ต้นฉบับ
- `public/images/categories/*.svg` — ภาพประกอบสินค้าแบบเวกเตอร์ สร้างใหม่สำหรับเว็บไซต์

## หมายเหตุสำคัญก่อนเผยแพร่จริง

- เว็บไซต์ต้นแบบ **ไม่มีการชำระเงิน ไม่มีการส่งข้อมูลส่วนบุคคลไปยังเซิร์ฟเวอร์ และไม่มีระบบรับออร์เดอร์จริง**
- ปุ่ม “ขอใบเสนอราคา” สร้างข้อความเพื่อคัดลอกเท่านั้น; ต้องเพิ่มเติมช่องทางติดต่อที่เจ้าของบริษัทยืนยันก่อนเปิดใช้งานจริง
- รายการสินค้าปัจจุบันเป็น **หมวดและรายการตัวอย่าง** ไม่ใช่สินค้าคงคลังจริง ไม่แสดงราคาสมมติ
- มีรูปภาพบริการจาก Unsplash CDN แบบตกแต่ง (ไม่ใช่ภาพสถานที่จริงของบริษัท); ควรเปลี่ยนเป็นภาพธุรกิจจริงที่ได้รับอนุญาตก่อนเผยแพร่
- ไม่มีการใส่เลขทะเบียนนิติบุคคล เบอร์โทรศัพท์ อีเมล ที่อยู่ หรือเลข VAT ที่ยังไม่ได้รับการยืนยัน
- โลโก้และสีใช้เพื่อแสดงผลตามตัวอย่างและเจ้าของควรตรวจสอบอีกครั้งก่อนใช้ในงานสาธารณะ
- หากต้องการระบบหลังบ้าน/รับออร์เดอร์จริง ต้องวางแผนฐานข้อมูลและความปลอดภัยแยกต่างหาก
